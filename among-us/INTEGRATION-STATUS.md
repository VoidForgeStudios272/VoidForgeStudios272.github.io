# Integration status

- The upstream project is copied directly into this directory. No Git submodule is used.
- GitHub Pages builds and hosts the frontend only.
- No backend URL is configured and no backend service is required for the static frontend deployment.
- Online rooms, matchmaking, and multiplayer features that depend on the Node.js/Socket.IO server are unavailable until the backend is intentionally enabled and deployed.
- The backend source remains in `backend/` for possible later use; it is not part of the GitHub Pages runtime.

See LICENSE and README.md for upstream attribution and setup instructions.
