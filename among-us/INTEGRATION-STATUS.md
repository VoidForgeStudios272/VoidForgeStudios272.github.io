# VoidForge Among Us integration

The upstream project is a React + Phaser 3 frontend and Node.js + Socket.IO backend. GitHub Pages can host the built frontend, but the multiplayer backend must be deployed separately.

Upstream source: https://github.com/arizkhalid/among-us-clone

The imported project must retain its MIT license and attribution. Binary game artwork has separate provenance that should be verified before redistribution.
